Clases

Clase 1

Explica qué es HTML5, su evolución y uso en el desarrollo web. Distingue entre páginas estáticas y dinámicas, desarrollador y diseñador, y los tipos de lenguajes de programación. También repasa los navegadores web y la historia de HTML.

Clase 2

Fundamentos de HTML5, el lenguaje que se utiliza para crear y estructurar páginas web. Se explica cómo está formado un documento HTML, el uso de etiquetas y atributos para dar formato al contenido y la importancia de las etiquetas semánticas como header, nav o footer. También se enseña cómo insertar texto, imágenes y aplicar estilos básicos.

Clase 3

HTML y el uso de hipervínculos y listas en el desarrollo web. Se enseña a los alumnos la importancia de maquetar correctamente un sitio web, comprendiendo el uso de enlaces internos, locales, remotos, y a correos electrónicos, además de cómo aplicar rutas absolutas y relativas. También se abordan las listas ordenadas, no ordenadas y de definición, mostrando cómo organizar la información de manera clara y estética.

Clase 4

Los alumnos aprenden HTML5 y CSS3 para crear y estilizar tablas, aplicando diferentes formas de definir estilos y unidades de medida, con el objetivo de mejorar la presentación de la información en sitios web de manera profesional.

Clase 5

HTML5 y CSS3 para crear y estilizar tablas, aplicando diferentes formas de definir estilos y unidades de medida, con el objetivo de mejorar la presentación de la información en sitios web de manera profesional.

Clase 6

Estilos CSS para mejorar la apariencia de las páginas web, utilizando pseudoclases y pseudoelementos para manipular elementos completos o partes de ellos. Se destacan los beneficios de los estilos externos, que facilitan el mantenimiento y la uniformidad en proyectos profesionales.
